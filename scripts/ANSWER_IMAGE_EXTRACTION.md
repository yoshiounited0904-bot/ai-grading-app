# ログイン必須ページの解答画像を回収する手順

## 目的

解答サイトにメールアドレスでログインしないと見られない PNG/JPG 画像を、スクショではなく画像URLとして回収する。

## 手順

1. 普段使っているブラウザで解答サイトにログインする。
2. 解答画像が表示されているページを開く。
3. ブラウザの開発者ツールを開く。
4. Console、または Sources > Snippets に `/Users/yoshitakaosawa/ai-grading-app/scripts/extract-answer-images-snippet.js` の中身を貼って実行する。
5. 新しいタブに画像一覧が表示される。
6. Chrome / Edge なら `同じフォルダに一括保存` を押し、保存先フォルダを選ぶ。
7. Safari などでフォルダ指定保存が使えない場合は `一括ダウンロード` を押し、ブラウザのダウンロードフォルダに保存する。
8. 必要に応じて `JSONをコピー` すると、あとで管理画面側の自動取り込みに使える画像URL一覧を取得できる。

## 注意

- パスワードはスクリプトに渡さない。
- ログイン状態のブラウザ内で実行するので、認証が必要な画像も拾える可能性が高い。
- サイトが画像を Canvas に描画している場合、`img` として抽出できない。その場合は別方式が必要。
- 複数画像の一括オープンはブラウザのポップアップ制限に引っかかることがある。
- `同じフォルダに一括保存` は File System Access API を使うため、Chrome / Edge などの対応ブラウザでのみ動作する。
